### 🛡️ A menu-bar client for AWS Client VPN
- The menu-bar icon shows connectivity by shape, and the panel lists every profile with one-click connect and disconnect.
- One tunnel at a time: connecting releases any other live tunnel first. Profiles matching a pattern you configure ask for confirmation, in the app and the CLI alike.
- Connections come back after sleep once the network does, and Connection Details (`⌘D`) shows throughput, routes, resolvers and recent transitions.

### ⌨️ A CLI that waits for the answer
- `conduit-vpn connect --wait` polls to a final state, so its exit code means connected, failed, or still waiting on a browser sign-in.
- Every vendor command is forwarded unchanged, run with a corrected `HOME` so the client works where `~/.config` is a symlink.
- `conduit-vpn doctor` checks the machine, and the client's own logs are pruned by age and size.

### 🔏 Signed, installed with one command
- Conduit.app and the CLI are signed with Conduit's own release certificate, and the installer refuses anything signed otherwise.
- `conduit-vpn update` installs the latest release, and `conduit-vpn doctor` checks that the installed app and CLI are the build it recorded.
